# 文体活动管理平台 - 核心模块实现分析

## 1. 项目概述

**文体活动管理平台** 是一个基于前后端分离架构的活动签到管理系统，主要功能包括：

- 管理员创建和发布活动，生成专属签到二维码
- 参与者通过扫描二维码或访问链接完成签到
- 实时查看签到名单和活动数据

技术栈：
- **前端**: Vue 3 + Vite + Element Plus
- **后端**: Spring Boot 2.7 + Spring Data JPA
- **数据库**: MySQL 8.0
- **部署**: Docker + Docker Compose

### 3.2 活动管理模块 (ActivityModule)

#### 核心实体设计 (`Activity.java`)

```java
@Entity
@Table(name = "activity")
public class Activity {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;                    // 活动ID
    
    @Column(nullable = false)
    private String title;               // 活动标题
    
    @Column(nullable = false)
    private LocalDateTime startTime;    // 开始时间
    
    @Column(nullable = false)
    private LocalDateTime endTime;      // 结束时间
    
    @Column(columnDefinition = "TEXT")
    private String description;         // 活动描述
    
    @Enumerated(EnumType.STRING)
    private ActivityStatus status;      // 活动状态：DRAFT/PUBLISHED/CLOSED
    
    @Column(unique = true, length = 64)
    private String checkinToken;        // 签到令牌(UUID)
    
    @CreatedDate
    private LocalDateTime createdAt;    // 创建时间
}
```

#### 活动状态枚举

```java
public enum ActivityStatus {
    DRAFT,      // 草稿状态
    PUBLISHED,  // 已发布（可签到）
    CLOSED      // 已关闭（不可签到）
}
```

#### 活动发布流程

```
管理员点击"发布"按钮
        ↓
AdminController.publishActivity(id)
        ↓
ActivityService.publishActivity(id)
        ├─ 校验：状态不能是PUBLISHED
        ├─ 生成UUID作为checkinToken
        ├─ 更新状态为PUBLISHED
        └─ 返回token给前端生成二维码
        ↓
前端使用qrcode库生成签到二维码
        ↓
参与者扫码 → 访问 /checkin/{token}
```

### 3.3 签到管理模块 (CheckinModule)

#### 签到记录实体 (`CheckinRecord.java`)

```java
@Entity
@Table(name = "checkin_record")
public class CheckinRecord {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(nullable = false)
    private Long activityId;        // 关联活动ID
    
    @Column(nullable = false, length = 100)
    private String name;            // 签到人姓名
    
    @CreatedDate
    private LocalDateTime checkinTime;  // 签到时间
}
```

#### 签到业务流程

```
参与者输入姓名点击签到
        ↓
PublicController.checkin(token, request)
        ↓
CheckinService.checkin(token, request)
        ├─ 通过token查询活动
        ├─ 校验活动状态：必须是PUBLISHED
        ├─ 校验姓名不能为空
        ├─ 创建签到记录
        └─ 保存到数据库
        ↓
跳转到签到成功页面
```

## 4. 前端响应式设计实现

### 4.1 Vue 3 响应式核心机制

项目采用 Vue 3 Composition API，核心响应式原理：

#### 4.1.1 ref() - 基础类型响应式

用于基本类型（字符串、数字、布尔值等）：

```javascript
// 活动列表页示例
import { ref, onMounted } from 'vue'

const activities = ref([])      // 活动列表
const loading = ref(false)      // 加载状态
const showCreateDialog = ref(false)  // 对话框显示状态

// 使用时需要访问 .value
const fetchActivities = async () => {
  loading.value = true
  try {
    activities.value = await getActivities()
  } finally {
    loading.value = false
  }
}
```

#### 4.1.2 reactive() - 对象类型响应式

用于复杂对象类型：

```javascript
// 签到页表单示例
import { reactive } from 'vue'

const form = reactive({
  name: ''  // 姓名字段
})

// 直接访问属性，无需.value
const handleSubmit = async () => {
  if (!form.name.trim()) {
    ElMessage.warning('请输入姓名')
    return
  }
  // ...
}
```

### 4.2 组件生命周期与数据加载

标准的页面数据加载模式：

```javascript
<script setup>
import { ref, onMounted } from 'vue'

// 1. 定义响应式数据
const data = ref(null)
const loading = ref(true)

// 2. 定义数据加载函数
const fetchData = async () => {
  loading.value = true
  try {
    data.value = await apiCall()
  } catch (error) {
    // 错误处理
  } finally {
    loading.value = false
  }
}

// 3. 组件挂载时自动加载
onMounted(fetchData)
</script>

<template>
  <!-- 4. 模板中使用响应式数据 -->
  <div v-loading="loading">
    <div v-if="data">{{ data }}</div>
    <el-skeleton v-else />
  </div>
</template>
```

## 6. API 请求封装与响应处理

### 6.1 Axios 实例配置

```javascript
// api/request.js
import axios from 'axios'
import { ElMessage } from 'element-plus'

const service = axios.create({
    baseURL: '/api',      // API 基础路径
    timeout: 5000         // 请求超时时间
})

// 响应拦截器
service.interceptors.response.use(
    response => response.data,  // 直接返回 data
    error => {
        // 统一错误提示
        ElMessage.error(error.response?.data?.error || '请求失败')
        return Promise.reject(error)
    }
)

export default service
```

## 7. 异常处理机制

### 7.1 全局异常处理器

```java
// GlobalExceptionHandler.java
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(NotFoundException.class)
    public ResponseEntity<Map<String, String>> handleNotFound(NotFoundException e) {
        Map<String, String> response = new HashMap<>();
        response.put("error", e.getMessage());
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(response);
    }
    
    @ExceptionHandler({IllegalStateException.class, IllegalArgumentException.class})
    public ResponseEntity<Map<String, String>> handleBadRequest(RuntimeException e) {
        Map<String, String> response = new HashMap<>();
        response.put("error", e.getMessage());
        return ResponseEntity.badRequest().body(response);
    }
}
```

## 8. 关键技术总结

### 8.1 后端技术亮点

1. **Spring Data JPA**: 简化数据访问层开发
2. **Lombok**: 消除样板代码（@Data, @RequiredArgsConstructor）
3. **JPA Auditing**: 自动维护创建时间（@CreatedDate）
4. **声明式事务**: @Transactional 注解管理事务
5. **全局异常处理**: 统一异常响应格式

### 8.2 前端技术亮点

1. **Vue 3 Composition API**: 更灵活的逻辑组织方式
2. **ref/reactive**: Vue 3 响应式系统核心
3. **Vue Router 4**: 路由懒加载，提升首屏性能
4. **Element Plus**: 开箱即用的组件库
5. **Axios 拦截器**: 统一请求/响应处理
6. **qrcode库**: 动态生成签到二维码

### 8.3 部署方式亮点

1. **Docker 容器化**: 每个服务独立容器
2. **Docker Compose 编排**: 一键启动整个系统
3. **服务依赖管理**: healthcheck 确保数据库就绪后启动后端
4. **数据卷持久化**: MySQL 数据持久化存储
5. **网络隔离**: 自定义网络实现服务间通信
